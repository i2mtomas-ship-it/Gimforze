# EvolvAI v1.2.0

## Entrenamiento y progresión

- Las series se guardan inmediatamente como borrador persistente al pulsar «Guardar serie».
- Si se sale del entrenamiento o la app se cierra, las series registradas se recuperan al volver a entrar en la misma rutina.
- Al finalizar el entrenamiento, el borrador se convierte en una sesión histórica y se elimina el borrador.
- Se muestra confirmación de cada serie guardada.
- Se mantiene la recomendación de la siguiente sesión basada en el histórico y el objetivo del ejercicio.
- Se muestra la sugerencia de carga/repeticiones al registrar una nueva serie.
- El descanso utiliza el descanso configurado para cada ejercicio.

## Catálogo y rutinas

- Se incorpora un catálogo local amplio de ejercicios para que la creación de rutinas no dependa de la disponibilidad de Internet.
- El catálogo local se combina con wger y el catálogo de respaldo cuando hay conexión.
- Se amplían ejercicios de pecho, espalda, hombros, brazos, piernas y core.
- Se mantienen los ejercicios personalizados.

## Robustez

- La carpeta Android del proyecto base no se sustituye mediante el actualizador.

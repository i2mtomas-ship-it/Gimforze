# EvolvAI v1.0.0

- Primera versión candidata completa para prueba de usuario.
- Identidad visual consolidada: fondo grafito, violeta/lavanda, menta y acentos controlados.
- Navegación inferior personalizada con Entrenar como acción central.
- Perfil accesible desde Inicio y vista de perfil alineada con el boceto aprobado.
- Rutinas, ejercicios, ejercicios personalizados, entrenamiento, progreso, objetivos y EvolvAI integrados en una misma experiencia.
- Histórico y métricas de volumen/progresión conservados.
- Persistencia local mediante SharedPreferences.
- El actualizador no modifica la carpeta android del proyecto destino.

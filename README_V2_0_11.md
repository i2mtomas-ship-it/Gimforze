# Gimforze v2.0.11

Reordena la pestaña IA para priorizar la creación de rutinas y mantiene las correcciones de v2.0.9.

Orden superior de la pestaña IA:
1. Crear una rutina con Gimforze
2. Analizar mi progreso
3. Generar plan inteligente
4. Propuesta semanal (resultado del plan inteligente)

Además, al volver del editor de rutinas se programa una actualización segura del listado para que las rutinas nuevas/editadas aparezcan sin refresco manual.

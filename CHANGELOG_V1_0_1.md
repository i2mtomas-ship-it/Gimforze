# EvolvAI v1.0.1

## Navegación y experiencia
- Añadida pestaña visible **Ejercicios** en la navegación principal.
- La navegación principal queda: Inicio · Ejercicios · Rutinas · Entrenar · Progreso · EvolvAI.
- Entrenar mantiene el tratamiento visual como acción principal.
- Se usa `IndexedStack` para conservar el estado de las secciones al navegar.
- El perfil deja de ser una barrera para explorar la aplicación.
- Inicio muestra accesos directos a Ejercicios, Rutinas, Entrenar y Progreso aunque el perfil esté incompleto.
- EvolvAI sigue accesible desde la navegación y desde Inicio.

## Ejercicios
- El catálogo y **Crear mi ejercicio** quedan accesibles desde una pestaña principal.
- Los ejercicios personalizados siguen guardándose localmente y aparecen junto al catálogo.

## Compatibilidad
- Se conserva la carpeta `android` del proyecto existente durante la actualización.

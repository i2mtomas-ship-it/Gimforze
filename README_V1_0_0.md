# EvolvAI v1.0.0

Versión candidata completa para la primera prueba global en Android.

## Diseño

Modo oscuro deportivo, grafito, violeta/lavanda como identidad, menta para progreso y navegación inferior personalizada.

## Funciones

Perfil, catálogo y ejercicios propios, rutinas por días, entrenamiento, registro de series, progreso, histórico, objetivos, nutrición y EvolvAI con motores locales de análisis y planificación.

## Nota

La capa de IA de esta versión utiliza los datos locales y motores de decisión de EvolvAI. No requiere una API externa para probar el flujo completo.
